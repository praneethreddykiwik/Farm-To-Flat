# India compliance register — Fooducia app

Written 13 November 2026, alongside the Phase 2 work.

**Read this first.** This is an engineer's reading of the rules, made to decide what the software should do. It is not legal advice, and the regulation numbers are quoted as we understood them — have a food-law consultant and a lawyer confirm them before you rely on any line here. What it _is_ good for: showing, rule by rule, what the app now does, and separating what code can settle from what only the business can.

Status words: **Done** — the app does it and a test or a screen proves it. **Partly** — the slot is built; a fact from you is missing. **Yours** — nothing in code can settle it.
